\section{Introducción y Objetivos del Proyecto}

El objetivo de esta práctica es desarrollar una aplicación web interactiva utilizando el framework \textbf{React 19} con \textbf{TypeScript} y \textbf{Tailwind CSS 4} empaquetado con \textbf{Vite}. La interfaz consume los datos en tiempo real de la API pública REST de Pokémon (\textit{PokéAPI}), gestionando la consulta y renderizado de los primeros \textbf{151 Pokémon}.

\subsection*{Requisitos Cumplidos}
\begin{itemize}[leftmargin=*]
    \item \textbf{Consumo de API REST:} Consulta directa al endpoint \href{https://pokeapi.co/api/v2/pokemon?limit=151}{\texttt{https://pokeapi.co/api/v2/pokemon?limit=151}}.
    \item \textbf{Filtrado y Búsqueda Reactiva:} Búsqueda instantánea por nombre/ID y filtrado por tipos elementales.
    \item \textbf{Detalle Extendido (Modal):} Consulta y renderizado de estadísticas base (HP, Ataque, Defensa, etc.), habilidades, peso y altura.
    \item \textbf{Módulo de Equipo (Team Builder):} Selección interactiva de un equipo de hasta 6 Pokémon.
    \item \textbf{Control de Versiones:} Repositorio en GitHub con commits semánticos y estructurado.
\end{itemize}

\section{Consumo del Endpoint PokeAPI}

La comunicación con la API se centralizó en el módulo de servicios con soporte para caché y procesamiento por lotes para evitar bloqueos:

\begin{lstlisting}[language=Java, caption={Servicio de consulta (\texttt{src/services/pokemonService.ts})}]
const API_BASE_URL = 'https://pokeapi.co/api/v2';

export async function fetchPokemonList(limit: number = 151): Promise<PokemonListResponse> {
  const response = await fetch(`${API_BASE_URL}/pokemon?limit=${limit}`);
  if (!response.ok) {
    throw new Error(`Error ${response.status}: Error al obtener el listado`);
  }
  return response.json();
}
\end{lstlisting}
